# Diseño Web Freelancer

Este proyecto corresponde a la segunda entrega práctica del itinerario de formación, enfocada en la transición de diseños básicos hacia estructuras web profesionales y dinámicas.

## 🎯 Objetivos del Proyecto
El objetivo principal fue consolidar el dominio de los sistemas de diseño actuales, asegurando que el código no solo se vea bien, sino que sea técnico y profesional.

- **Dominio de Layouts**: Implementación de **CSS Grid** para la estructura global y **Flexbox** para componentes internos.

- **Arquitectura CSS**: Aplicación de buenas prácticas para lograr una hoja de estilos organizada, facilitando el mantenimiento y futuras actualizaciones.

- **Adaptabilidad (Responsive)**: Desarrollo de una interfaz 100% adaptable a distintos dispositivos, aplicada con precisión en:

- **Formularios** de contacto/registro.

- **Ventanas** de exposición de cursos.

- **Navegación** general.
