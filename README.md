# Diseño Web Freelancer

Este proyecto corresponde a la segunda entrega práctica del itinerario de formación, enfocada en la transición de diseños básicos hacia estructuras web profesionales y dinámicas.

A lo largo de la realización de este proyecto fuimos interiorizando conceptos y observando simultaneamente cómo ir adaptando nuestra web a las distintas resoluciones que pudieran tener los usuaruios mediante herramientas como ResponsivelyApp y DevTools de distintos navegadores
